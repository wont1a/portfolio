# NØVA FITNESS — New body. New standard.

Лендинг фитнес-клуба в Москве (Дизайн-завод «Флакон», м. Дмитровская).

- `index.html` — вся страница: стили и скрипт внутри, без фреймворков.
- `assets/js/scene.js` — собранная 3D-сцена зала (three.js 0.169), фон первого экрана.
- `src/scene.js` — исходник сцены. Пересборка:
  ```bash
  npm i three@0.169.0 esbuild@0.24.0
  npx esbuild src/scene.js --bundle --minify --format=iife --target=es2018 --outfile=assets/js/scene.js
  ```
- `assets/img/poster.webp` — кадр зала, который виден, пока загружается 3D.
- `assets/fonts/` — Inter и Tektur (латиница и кириллица), без внешних запросов.

Первый экран сам облетает зоны клуба каждые 8 секунд, пока посетитель не выберет зону сам: удобно записывать рилс прямо с экрана. Кнопка «Звук» включает клубный бит, и кольцо Ø пульсирует в такт.
